# Containers

Use callout blocks to make tips, important information, warnings, and destructive actions easy to scan.

## Examples

> **Tip**
>
> Keep an optional explanation close to the task it supports.

> **Info**
>
> This note provides context without interrupting the main flow.

> **Warning**
>
> Point out a condition that could cause a user to lose progress.

> **Danger**
>
> Explain an action that cannot be undone.

> **Details: Custom title**
>
> Use a concise title when the callout needs a specific label.
