# Introduction

CMFRT is a reusable React component library with a focused set of interface building blocks. This site documents the components, their states, and the patterns used across CMFRT projects.

## What you can do here

- Browse interactive components and copy working JSX examples.
- Explore shared icons and their names.
- Read setup, usage, and API notes.

## Start using the library

Open [Getting started](/guide/start/getting-started) for setup instructions, or browse [Components](/guide/components) to see the available UI.

## Component pages

Each component has its own page with a live preview, source example, and available states. The navigation on the left groups these pages under **Components**.
